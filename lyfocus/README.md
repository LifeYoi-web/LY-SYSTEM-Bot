# LY Focus — تطبيق إدارة الوقت ⏱️🔥

تطبيق أندرويد لإدارة الوقت والعادات، مصمّم خصيصًا لشخص "ما ينتبه للوقت" — بهوية **LY** (برتقالي متوهّج على أسود) وشعارك.

كل بياناتك محفوظة **على جهازك فقط** (بدون سيرفر، بدون حساب، بدون إنترنت).

---

## ✨ المميزات

- **🗓️ اليوم** — مهام اليوم مع وقت ومدة وأولوية، وشريط إنجاز يومي.
- **⏱️ تركيز (بومودورو)** — مؤقّت 25/5 قابل للتعديل، مع **تنبيه + اهتزاز + صوت** عند انتهاء الجلسة. هذا قلب التطبيق لأنه يخليك "تحس" بالوقت يمشي.
- **🔥 عاداتي** — متتبّع عادات مع عدّاد سلسلة (streak) لكل يوم تلتزم فيه. فيه عادات جاهزة مقترحة تقدر تفعّلها بضغطة.
- **🧭 دليلك** — نصائح واضحة: وش العادات اللي **تغيّرها** ووش اللي **تثبّته** (مكتوبة لك تحت).
- **🔔 جرس الساعة** — تنبيه كل ساعة يذكّرك بمرور الوقت (اختياري من الإعدادات).
- **💾 نسخة احتياطية** — تصدير/استرجاع بياناتك كملف.
- **ساعة حيّة** فوق الشاشة دائمًا.

## 📲 طريقة التثبيت

### الخيار الأول: APK جاهز (الأسهل)
1. كل ما يتغيّر التطبيق، يبني **GitHub Action** ملف APK تلقائيًا.
2. روح تبويب **Actions** في GitHub → افتح آخر تشغيل لـ "Build LY Focus APK" → نزّل **`LY-Focus-APK`** من قسم Artifacts.
3. انقل الملف لجوالك، فعّل "تثبيت من مصادر غير معروفة"، وثبّته.

### الخيار الثاني: PWA (بدون انتظار البناء)
1. ارفع محتوى مجلد `www/` على أي استضافة HTTPS (مثل GitHub Pages / Netlify / Vercel).
2. افتح الرابط من متصفح **Chrome** على جوالك.
3. القائمة (⋮) → **"إضافة إلى الشاشة الرئيسية"** — بيشتغل مثل تطبيق عادي وأوفلاين.

## 🛠️ بناء الـ APK محليًا (للمطوّر)

يتطلب: Node 20+، JDK 21، Android SDK.

```bash
cd lyfocus
npm install
npx cap add android          # ينشئ مشروع أندرويد
npx @capacitor/assets generate --android   # يولّد الأيقونات من شعارك (يحتاج resources/icon.png)
npx cap sync android
cd android && ./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

## 🧭 دليلك: وش تغيّر ووش تثبّت

### ❌ عادات لازم تغيّرها
| العادة | ليش تأثّر | الحل العملي |
|---|---|---|
| **نوم/صحوة بمواعيد عشوائية** | جسمك ما يعرف متى يشتغل، فيومك كله يصير متذبذب | ثبّت **وقت صحوة واحد** حتى بالإجازة، لمدة أسبوعين |
| **تبدأ يومك بالجوال** | أول 30 دقيقة سوشيال ميديا تخطف تركيزك لباقي اليوم | الجوال بعيد عن السرير + **أول ساعة بدون شاشة** |
| **تشتغل بدون خطة مكتوبة** | بدون خطة، غيرك يمشّي يومك، وتحس مشغول بدون إنجاز | اكتب **3 مهام فقط** لبكرة كل ليلة (ثلاثة، مو أكثر) |
| **ما تحس بالوقت يمشي** | لأنك ما تقيسه — والوقت اللي ما ينقاس يضيع | استخدم **مؤقّت التركيز** بالتطبيق |
| **تسوي كل شي مرة وحدة** | التنقّل بين المهام يضيّع ~40% من تركيزك | مهمة وحدة كل جلسة، واقفل الباقي |
| **تسهر بدون هدف** | يأكل من يوم بكرة كامل | حدّد وقت "إغلاق" لليوم، بعده راحة فقط |

### ✅ أشياء خلّها زي ما هي
- **طموحك ورغبتك للتغيير** — إنك طلبت أداة واعترفت إنك تبي تتحسن = نص الطريق.
- **وعيك بنقطة ضعفك** — معرفتك إنك "سيء بالتوقيت" ميزة، تقدر تشتغل على شي محدد.
- **شغفك ببراندك (LY)** — اهتمامك بهويتك يثبت إنك تنجز لما الشي يهمّك. وجّه نفس الطاقة لوقتك.

> 📌 **قاعدة ذهبية:** ابدأ **أصغر** مما تتخيّل. عادة وحدة كل أسبوع. الالتزام الصغير المستمر يغلب الحماس الكبير المؤقت.
